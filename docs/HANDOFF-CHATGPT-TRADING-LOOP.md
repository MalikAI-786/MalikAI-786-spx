## Part 2 — Five defects that must be fixed

### D-1 — Broker names and click-by-click instructions (HIGH — compliance)

The Sep 8 body contained a `HOW TO PLACE IT` block naming two brokers and giving
order-entry steps.

`scripts/SKILL.md` §0.7 makes this a hard halt condition:

> The strings `"Option Alpha"` and `"Tastytrade"` MUST NOT appear in the email
> body. Click-by-click broker instructions are dashboard-gated only.

This implements audit finding **F-01 (High severity)** — holding-out risk under
the Investment Advisers Act of 1940 §202(a)(11). An educational newsletter that
also names a live broker and walks the reader through order entry reads as
investment advice, not research. `docs/SIGNAL-SOURCES.md` records that the entire
v5.0 redesign was written to distance the newsletter from exactly this.

**Fix:** delete the `HOW TO PLACE IT` section. Publish the structure in the
generic educational form only — structure name, strikes, credit target as a
fraction of width, max defined loss. No broker, no order steps, no "submit at".

### D-2 — No accountability lead (HIGH — contract violation)

`scripts/SKILL-accountability.md` §1 is mandatory and says the email **does not
start with today's forecast.** Sep 8 buried the recap mid-body and led with the
trade plan.

**Fix:** the first block after the header must be:

```
IF WE HAD FOLLOWED YESTERDAY'S PUBLISHED MODEL SETUP: {plain-English result}.
Synthetic disciplined P&L: {signed $ per standardized 1-lot}.
Verified cumulative P&L: {signed cumulative} across {n} audited days.
```

Then the §3 scorecard, then the diagnosis, then today's call.

### D-3 — Direction and structure were blended (MEDIUM)

Sep 8 called the Sep 2 result "a clean miss." It was not. SPX closed 7,666.60,
**23 points below the 7690 short call** — the direction was wrong and the spread
still expired out-of-the-money. **Direction MISS, structure HIT.**

Collapsing those two into "miss" destroys the one diagnostic that makes the model
improvable: a wrong directional read with correct strike placement is a different
failure from a wrong read that also lost money.

**Fix:** score direction, structure, execution and discipline separately, always.

### D-4 — An unaudited win rate contradicted the audited ledger (HIGH — accuracy)

Sep 8 published *"4W/1L/2SD of 7 scored, 80% win rate."*

The audited ledger says: **+$120 across 16 audited days, 1 win / 1 loss / 8
stand-downs, 50% win rate, direction hit rate 62.5%, structure hit rate 83.3%.**

80% vs 50% is not a rounding difference. The published figure was materially
rosier than the evidence supports, and it did not come from the ledger.

**Fix:** every performance number in the email must come from
`dashboard/data/performance.json`, generated by `accountability_track.py build`.
If that file cannot be read, print `N/A — ledger unavailable this run`. Never
compute a win rate in the chat context.

### D-5 — No git access, so nothing was ever recorded (HIGH — root cause)

Sep 8's own system note: *"Dashboard/git still broken (fatal: not a git
repository) — report saved via file tools only."*

This is why the ledger sat at 2026-08-27 while publications continued, why the
dashboard went stale, and why D-4 happened — with no ledger to read, the model
reconstructed a win rate from memory.

**Fix, in priority order:**
1. Give the task a working clone of `MalikAI-786/MalikAI-786-spx`, or
2. If git is impossible, have the task emit a machine-readable append line at
   the end of every run (format in Part 4) and let a human or Claude commit it.

Without one of these, the accountability layer cannot function at all.

## Part 4 — The loop command

Paste this as the ChatGPT scheduled-task instruction. It is self-contained.

```
SPX 0DTE MORNING RUN — 9:00 AM ET, US trading days only.

ROLE
You are the sole publisher of the SPX 0DTE morning note. Educational research
only, synthetic paper trades, real money is never moved.

STEP 0 — TRADING DAY GATE
If today is a weekend or a US market holiday (New Year's, MLK, Presidents',
Good Friday, Memorial, Juneteenth, July 4, Labor Day, Thanksgiving, Christmas):
stop. Publish nothing. Silence on a closed day is correct.

STEP 1 — TIMING GATE
Note the current ET time.
  - Before 9:30 ET  -> full normal run.
  - After 9:45 ET   -> the entry window is gone. Publish the
    "LATE RUN — NO TRADE ISSUED" form: state the actual run time, state that
    the entry window and possibly the close were missed, claim no position,
    score no trade. NEVER back-date a signal to look on time.
This gate exists because the 2026-09-01 run fired at 8:29 PM ET and published
as though it were a morning note.

STEP 1B — BINARY-EVENT GATE
Check whether today carries a scheduled binary: an FOMC decision, CPI, PPI, or
NFP. On those days do NOT publish a full-conviction directional call. Either
stand down, or cut size and say so explicitly in the email — the composite is
scored entirely on pre-event information that the event is about to invalidate.
Name the event and its release time in the body.
This is not theoretical. The Sep 10 email correctly flagged "Fri 9/11 CPI --
size down into it" and "Sept 15-16 FOMC, ~60% hike odds" as the month's two
biggest risks, and then the pipeline went dark for both of them. An event gate
that is only prose in the WHY section is not a gate.

STEP 2 — LOAD THE LEDGER FIRST, BEFORE ANY MARKET DATA
Read dashboard/data/performance.json (regenerate with
`python3 scripts/accountability_track.py build` if you have the repo).
Extract: verified_cumulative_pnl, verified_days, wins, losses, stand_downs,
win_rate, expectancy, max_drawdown, direction_hit_rate, structure_hit_rate,
coverage_note, latest_effective_result, diagnosis.
If the file is unreachable, every performance figure in today's email is
"N/A — ledger unavailable this run". Do NOT reconstruct numbers from memory.
This is the D-4 rule and it is absolute.

STEP 3 — SCORE YESTERDAY, FOUR WAYS SEPARATELY
For the most recent published setup:
  direction  — did the sign of the composite match the realized SPX move?
  structure  — given that move, did the published spread make or lose money?
               A bear call spread wins if SPX closes BELOW the short call.
               A bull put spread wins if SPX closes ABOVE the short put.
               Direction can be wrong while structure still wins. Say so.
  execution  — would the published trigger/invalidation/exit have helped?
  discipline — did a stand-down or stop avoid a larger loss?
Never state a dollar P&L unless a fill was actually published. If no fill
exists, record the verdicts and say "exact dollar P&L not stated".
Never infer a spread fill from the index close alone.

STEP 4 — WRITE THE LEAD (this is the first thing in the email)
  IF WE HAD FOLLOWED YESTERDAY'S PUBLISHED MODEL SETUP: <plain English>.
  Synthetic disciplined P&L: <signed $ or "not stated">.
  Verified cumulative P&L: <signed $> across <n> audited days.
  <coverage note if backfill is incomplete>
For a stand-down: "we would have stayed flat. Synthetic disciplined P&L: $0.
The model took no exposure." A stand-down is never a win.
Then the scorecard table: cumulative P&L, W/L/SD, win rate, avg win, avg loss,
expectancy, max drawdown, direction hit rate, structure hit rate, coverage.
Print "N/A — insufficient verified observations" rather than manufacturing
precision on a thin denominator.

STEP 5 — TODAY'S FIVE BUCKETS, each scored in [-2.0, +2.0] with a rationale
  futures       weight 0.30  ES/NQ/YM overnight change
  macro         weight 0.20  today's US releases; surprise vs consensus if
                             already printed, expected impact if scheduled
  news          weight 0.15  last 16h SPX-relevant headlines
  international weight 0.15  Nikkei, Hang Seng, DAX, FTSE, Euro Stoxx
  sentiment     weight 0.20  VIX, VVIX, put/call
Cite the actual number behind every score. If a bucket cannot be sourced, say
so and mark it partial coverage — do not silently score it from nothing.

STEP 6 — CALIBRATION OVERLAY
From the rolling 10-day per-bucket correlation with next-day SPX change:
  corr >= 0.40 -> TRUSTED,  weight x1.10
  |corr| < 0.15 -> WEAK,    weight x0.85
  corr < 0.0   -> WRONG-WAY, weight x0.50 (discount magnitude, do not flip sign)
Re-normalize weights to sum to 1.0. Apply an extra x0.75 to the bucket that was
most directionally wrong yesterday.
If the correlation history does not exist, say "calibration not applied this
run" and use base weights. Do not invent multipliers.

STEP 7 — COMPOSITE AND LABEL
composite = sum(weight_i * score_i), clipped to [-2.0, +2.0].
  >= +1.00        BULLISH
  +0.30 to +1.00  LEAN BULLISH
  -0.30 to +0.30  STAND-DOWN
  -1.00 to -0.30  LEAN BEARISH
  <= -1.00        BEARISH

STEP 8 — STRUCTURE (educational form only)
sigma = SPX_NOW * (VIX/100) * sqrt(1/252)
  Bullish  -> Bull Put Spread: short put ~ SPX-1.0sigma, long put ~ SPX-1.5sigma
  Bearish  -> Bear Call Spread: short call ~ SPX+1.0sigma, long call ~ SPX+1.5sigma
  Stand-down -> no structure, no invalidation level, $0 recorded
Publish: structure name, both strikes, credit target as a fraction of width,
max defined loss, invalidation level.
FORBIDDEN in the body: the strings "Option Alpha", "Tastytrade", "Trade at",
"signal to enter", and click-by-click order-entry steps. Broker-specific
execution is dashboard-gated only. This is finding F-01 and it is a hard halt.

STEP 9 — BODY ORDER
accountability lead -> scorecard -> why it worked/failed -> today's bias and
bucket table -> calibration -> lessons learned -> evidence both sides -> vol,
levels, catalysts -> invalidation -> educational structure -> pre-flight
checklist -> rolling synthetic P&L -> dashboard link -> NOT-INVESTMENT-ADVICE
box (verbatim, SKILL.md §8) -> "Questions or something look off? Reply to this

STEP 10 — DISTRIBUTION

educational disclaimer for any recipient.

STEP 11 — EMIT THE LEDGER LINE (do this even if you cannot reach git)
End every run with this block so the day can be recorded:

  LEDGER_APPEND
  date=YYYY-MM-DD
  bias_score=<signed composite>
  bias_label=<LABEL>
  stand_down=<true|false>
  structure=<bull_put_spread|bear_call_spread|stand-down|no-trade>
```
